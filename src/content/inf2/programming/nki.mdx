NKI (Neuron Kernel Interface) is how you write your own kernels for a NeuronCore. A kernel is a Python function
decorated with `@nki.jit`. When it is called it is **traced** — executed symbolically — into a list of engine
instructions, compiled into a NEFF binary, and launched on the device like any other op.

The closest GPU analogue is not CUDA C++ but something like Triton with the training wheels removed: there are no
threads or warps. You allocate tiles explicitly, move them with DMA, and call one function per hardware
instruction.

## The two layers of the API

- **`nki.language` (`nl`)** — buffers, dtypes, loops: `nl.ndarray(shape, dtype, buffer=nl.sbuf)`,
  `nl.static_range`, `nl.affine_range`.
- **`nki.isa` (`nisa`)** — the instructions: `nisa.dma_copy`, `nisa.nc_matmul` (Tensor Engine),
  `nisa.tensor_tensor` / `tensor_scalar` / `tensor_reduce` (Vector Engine), `nisa.activation` (Scalar Engine),
  `nisa.iota`, `nisa.max8` and friends.

Most `nisa` calls take an `engine=` argument or have a fixed engine, so you decide which of the four engines does
each piece of work. The compiler schedules the four instruction streams and inserts the semaphores between them.

## What you control, and what you do not

You control: tile shapes and placement, the partition layout of every tensor, which engine runs each op, the order
of DMAs, how much is resident in SBUF. You do not write synchronisation, register allocation or instruction
scheduling — the compiler does that from your data dependencies.

## Calling a kernel from PyTorch

With torch-neuronx a kernel is called directly on `neuron` tensors and composes with eager PyTorch:

```python
x = torch.randn(2048, 32, dtype=torch.bfloat16).to("neuron")   # [features, tokens]
y = rmsnorm_linear_t(x, norm_w, w_tiled)                        # traced + compiled on first call
```

The first call per distinct input shape (and per value of each static argument) traces and compiles; later calls
reuse the NEFF. See <T id="programming/tracing-and-compilation">tracing and compilation</T>.
